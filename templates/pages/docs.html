Architecture du projet

Le système suit une structure Django modulaire avec séparation claire des responsabilités :

coop-ca-amifond/
├── authentication/     # Custom User, JWT, RBAC, rôles coopérative
├── apps/
│   ├── enterprise/     # Agrégat racine (Entreprise, Branches, Exercices)
│   ├── accounts/       # Plan comptable PC-EMF (~1532 comptes)
│   ├── tiers/          # Tiers Classe 4 (personnes physiques/morales)
│   ├── customers/      # Clientèle (KYC, IBAN, comptes, épargne)
│   ├── accounting/     # Comptabilité générale (journaux, écritures)
│   ├── treasury/       # Trésorerie (sessions de caisse, opérations)
│   ├── loans/          # Crédits (CTA/MLT, amortissement, provisions)
│   ├── shares/         # Parts sociales (souscription, libération, retrait)
│   ├── events/         # Moteur de règles comptables (15 règles PC-EMF)
│   ├── client/         # Portail client self-service (lecture seule)
│   ├── manager/        # Portail gestionnaire back-office (CRUD)
│   └── common/         # Utilitaires partagés (Country, City)
├── core/               # Utilitaires transverses (Document, MediaFile, Notification)
├── config/             # Settings, URLs, WSGI, Swagger
└── pages/              # Interface HTML + Design System
